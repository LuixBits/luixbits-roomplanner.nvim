# Contributing

The root [`CONTRIBUTING.md`](../../CONTRIBUTING.md) is the authoritative
contribution guide. It covers the change workflow, architectural boundaries,
tests, commit style, extension points, licensing, and pull-request evidence.
Project participation follows the root [code of
conduct](../../CODE_OF_CONDUCT.md).

Read these chapters when a change touches their contract:

- [Architecture](architecture.md) for module and data-flow boundaries.
- [Compatibility policy](compatibility.md) for public interfaces and schema
  changes.
- [Architecture decisions](../adr/README.md) for durable cross-layer choices.
- [Installation](../getting-started/installation.md) for a local development
  checkout.

Run `./scripts/test.sh` for an ordinary change. Release-oriented work uses the
complete gate and manual matrix in [`RELEASE.md`](../../RELEASE.md).
